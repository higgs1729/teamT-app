# no-test

このスキルが指定されたら、続くプロンプトでプログラム（コード・設定ファイル等）を変更した後、
**通常なら行う動作確認のステップを一切スキップして、変更が完了した時点で即座に応答を終える**。

## 何をしないか

変更後に以下を一切行わない:

- テストの実行（単体テスト・統合テストなど）
- ビルド・コンパイルの確認
- lint / 型チェックの実行
- プレビューサーバーの起動やブラウザでの動作確認
- 変更内容を裏付けるためのログ確認・追加のコード読み直し

## 何をするか

- 求められた変更そのものは通常どおり丁寧に行う（品質を落とす指示ではない）
- 変更が終わったら、簡潔に「何を変更したか」を報告してすぐに終了する
- 検証を省略したことを一言添えてよい（例: 「検証はスキップしています」）が、長々と言い訳や注意書きを書く必要はない

## なぜこうするか

動作確認そのものに価値がないわけではなく、状況によっては確認のオーバーヘッド（サーバー起動・テスト実行の待ち時間など）を避け、
変更をとにかく素早く積み重ねたい場面がある。ユーザーが後でまとめて確認する、あるいは今回の変更が小さく自明で確認が不要と判断している場合に、
このスキルを使うことでその意図を尊重する。

## 注意

- このスキルは「このプロンプト以降の変更」に対する一時的な指示であり、恒久的な設定ではない。次に通常のプロンプトが来たら、いつもどおり動作確認を行ってよい。
- 変更自体を雑にしてよいという意味ではない。読みやすく正しいコードを書くことと、事後の動作確認をしないことは別の話。
