# stop

`/execute` の対になるスキル。`.Codex/launch.json` の `springboot`（ポート8080）と `static`（ポート5500）を、
稼働中であれば両方止める。

## 手順

1. 稼働中のプレビューサーバー一覧を取得する（`preview_list` 相当のツール）。
2. 一覧の中から `name` が `springboot` または `static` のものを探す。
   - 名前ではなく `port` が `8080` / `5500` のもので判定してもよい（起動時の名前解決の揺れに強い）。
3. 見つかったサーバーをそれぞれ停止する。
4. 停止後にもう一度一覧を取得し、実際に消えたことを確認する。
5. ユーザーには「何を止めたか」を簡潔に報告する。
   - 元々どちらも起動していなかった場合は、その旨を伝えて終了する（エラー扱いにしない）。
   - 片方だけ起動していた場合は、その1つだけ止めて報告する。

## 注意

- `springboot` と `static` はそれぞれ別プロセスなので、どちらかの停止に失敗してももう片方は独立して止めてよい。
- このスキルは `execute` スキルが管理しているプレビューサーバーだけを対象とする。ユーザーが手動でターミナルから起動した別プロセス（`mvn spring-boot:run` を直接叩いた場合など）はこの仕組みの外にあるため関知しない。
