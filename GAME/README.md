# タスク一覧

## ゲーム要素の仕様変更
現状の体力攻撃力防御力は撤廃
コイン制度にしてコインを消費してゲームをプレイする(ゲームクリアで難易度に応じたコインゲット)
ゲーム画面はステータス画面＋ステージ画面ではなく一つのゲーム画面に統合し、そこでコインの枚数の確認とゲームのプレイができる
コインはがーむ画面とヘッダー左で確認できる

## /GAME内のhtmlについて、終了処理を追加 (本番ビルド時は'*'を具体的なURlに差し替える)
window.parent.postMessage({ type: 'game:ended',coin: 'コイン枚数'}, '*');
coinについて、0ならゲームオーバー、1以上でクリアと判定する。

## /GAME内のhtmlについて、開始処理
消費するコイン枚数を決めておいて、その分コインを消費してプレイできるようにする
