Chronicling America 新聞検索

Library of Congress の歴史新聞コレクションから、キーワードに関係する新聞ページやタイトルを検索します。認証なしで公開されているJSON APIの入口を、研究メモ作り向けに触れるページです。

検索語を入れて「検索」を押してください。

APIメモ

公式情報では、Chronicling America のデータは LoC.gov API からJSON/YAMLなどで取得でき、APIキーは不要です。アクセス頻度には配慮します。

Auth: No Format: JSON Provider: LoC Collection: Newspapers

ライブ取得に失敗した場合

ブラウザのCORSやネットワーク制限で取得できない場合は、下のサンプルカードに切り替わります。公式ページへのリンクとリクエストURLの形は確認できます。
