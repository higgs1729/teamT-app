user-agent / ApicAgent

UA文字列から、
端末の正体を素早く読む。

ApicAgent は User-Agent を解析して、端末・OS・ブラウザ情報を返します。UA の置き換えや共有文字列の診断に向いたページです。

UA解析文字列をそのまま貼って診断できます。
ブラウザ入力現在の User-Agent を自動投入できます。

診断する

UAを入力して解析します。空欄なら現在のUAを使います。

no keyUAJSON
UA を入力して解析してください。

返却データ

JSON をそのまま表示し、見やすい要約も出します。

見どころ

  • UA の手入力と現在値の比較ができる
  • ブラウザごとの差を確認しやすい
  • API 応答をそのまま保存できる
