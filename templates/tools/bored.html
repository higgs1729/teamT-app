random activity / Bored

退屈しのぎの予定を、
1クリックで拾う。

Bored API は、気分転換用のアクティビティ案を返します。人数や種類を指定して、次にやることをサクッと決める用途に向いています。

気軽な提案今の気分に合うアクティビティを引きます。
条件指定参加人数や種類を変えて再抽選できます。

提案を引く

条件を少し変えながら、次にやることを決めます。

no keyrandomactivity
条件を選んで、アクティビティを引いてください。

返却データ

activity / participants / price / accessibility などを表示します。

見どころ

  • 用途別のアクティビティ候補を引ける
  • 人数を入れて実用寄りに絞れる
  • 空き時間の決定を早くできる
